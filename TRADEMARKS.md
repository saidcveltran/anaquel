# Name and logo

The code is Apache-2.0 (see `LICENSE`). Section 6 of that licence means it does
not grant the right to use the project's name or logo.

- You may say that your site is **built with Anaquel**, and use the name to
  describe the software truthfully.
- You may not present a modified version, or a service of your own, as Anaquel
  or as endorsed by the project.
- The project mark in `themes/folio/assets/brand/mark.svg` is part of the
  default theme. A fork should replace it with its own.
